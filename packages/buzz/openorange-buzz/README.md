# OpenOrange

Talk to your OpenOrange agents, such as Clem, in Buzz. Mention the agent in a
thread and it answers there from your Sunport; each thread is one continuing
conversation.

## Getting started

1. Install `oo`, OpenOrange's command line, from https://app.openorange.ai/connect
   on this computer, and run `oo login` in a terminal.
2. In Buzz, open **Agents**, choose **New agent**, then **Custom**, **Harness**
   and **OpenOrange**.
3. Mention the agent in a thread. It answers your own mentions while Buzz
   Desktop is open.
