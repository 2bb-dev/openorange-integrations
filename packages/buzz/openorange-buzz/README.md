# OpenOrange

Talk to your OpenOrange agents, such as Clem, in Buzz. Mention the agent in a
thread and it answers there from your Sunport; each thread is one continuing
conversation.

## Getting started

1. Install `oo`, OpenOrange's command line, from https://app.openorange.ai/connect
   on this computer, and run `oo login` in a terminal.
2. In Buzz, open **Agents**, choose **New agent**, then **Custom**, **Harness**
   and **OpenOrange · while Buzz is open**. It works in any community.
3. Mention the agent in a thread. It answers your own mentions while Buzz
   Desktop is open on this computer.

## Always on

Choose the harness **OpenOrange · always on** instead, under Remote, and your
Sunport runs the agent in Buzz itself: it answers even while Buzz Desktop is
closed and this computer is off. It is for communities Buzz hosts, and needs a
current Sunport.

1. With `oo` installed and signed in as above, create the agent with the
   harness **OpenOrange · always on**.
2. Your browser opens once for you to sign in to Buzz. If the setup stops
   before it finishes, choose **Finish setup** on the agent.
3. Add the agent to a channel in Buzz and mention it there. It answers only
   your own mentions; anyone else who mentions it gets one short note that it
   answers only its owner.

Buzz asks for a new sign-in from time to time. Until you give it one, the agent
doesn't answer: run `oo buzz renew` in a terminal, which opens your browser to
sign in again.
